# Changelog

## 0.1.0 — 2026-09-08

Initial development release establishing the Humboldt Current System environmental-data workflow architecture.

- defined the external heavy-data store contract;
- established domain, product, variable, processing, and path configuration;
- added catalog tables for products, variables, files, coverage, and checksums;
- added catalog schemas and automated repository validation;
- documented the separation between `oceancube`, this workflow, the external data store, and downstream scientific repositories;
- added Quarto workflow documentation and repository metadata.
